# פיילוט סוכן טיוטת מייל: איך מריצים

עד שהסוכן ייבנה באתר (Issue #106), Claude מריץ אותו בשרשור. טיוטה בלבד, לא שולחים.

1. **משיכת הפוסט:** `GET /api/posts/<slug>` באתר הטסט (או אותה שאילתה מול מסד הטסט: פוסט שפורסם בלבד, הגרסה הנוכחית). שומרים את `post_version_id`.
2. **בניית המייל:** `python3 -I build_email.py post.json "<מסכת>" <כתובת האתר> > email.json`. בטסט הקישור לאתר הטסט, בייצור לכתובת הייצור.
3. **בדיקות יחידה:** `python3 -m unittest docs/runbook/email/test_build_email.py`.
4. **טיוטה:** מחפשים קודם טיוטה קיימת לפי הנושא והנמען. אם יש, מעדכנים אותה ולא יוצרים שנייה. אם אין, יוצרים.
5. **צרופה:** שלי מצרפת את תמונת הפוסט המקוצר בעצמה, **אחרון**, אחרי שהטקסט סופי. כלי הטיוטות מוחק צרופות בכל עדכון. לכן אם לטיוטה יש צרופה (`has:attachment`), לא מעדכנים אותה. אומרים לשלי ומחכים להנחיה.
6. **שליחה:** רק שלי או אבי, ידנית.
