# תכנון בדיקות MVP5: פוסט מקוצר

עודכן: 28.10.2026 (גרסה 1, לפי PRD 0.7 ומפרט המסכים שאושר ב-28.10.2026). הפוסט המקוצר באתר כבר בטסט (פיילוט 28.10.2026, PR #92 ו-#95), ל-11 הפוסטים האחרונים. גרסה 1.1 (29.10.2026) מוסיפה את תהליך הפיילוט (סעיף ד), וגרסה 1.2 את בדיקות שני הסקילים (סעיף ה). מסך הניהול של הפוסט המקוצר והשליחה בוואטסאפ עוד לא נבנו, ולכן מקרי הבדיקה שלהם תכנון מראש. נכתב כך שבודק אחר יוכל להריץ אותו לבד.

מקורות: PRD 0.7 (עקרון 2, 2.4 ג', 3.5, MVP5 בטבלת ה-MVP, מילון), מפרט המסכים (עמוד פוסט, "פוסט מקוצר (בעלים, MVP5)"), המוקאפ המאושר, תפיסת הפתרון (6.4). בכל סתירה ה-PRD קובע.

## מה נכלל ב-MVP5

1. **לא טיזר.** גרסה מתומצתת של הפוסט כולו, לקוראים מעמיקים שלא ייכנסו לאתר. נשלחת ישירות בוואטסאפ.
2. **תמונה אחת 1080 על 1920**, נקראת בטלפון בלי גלילה. כותרת משותפת (הדף היומי, מסכת ודף, כותרת הפוסט, "הפוסט בקצרה"), פתיחה מודגשת בתיבה בצבע שמנת עם קו זהב, כותרות כחולות עם קו זהב, ובתחתית קוד QR לפוסט (`?src=short`).
3. **שתי חלופות**: א לפי סדר הפוסט עם כותרות, ב שאלות ותשובות. כל משפט לקוח מהפוסט.
4. **אישור לגרסה**: מוצג באתר רק אחרי אישור פעולה לגרסה הנוכחית של הפוסט. שינוי בפוסט או בתוכן מבטל.
5. **באתר**: אחרי הסטטוס, עם "הורדת התמונה" לכל מבקר, וקיצור "הפוסט בקצרה". פוסט בלי פוסט מקוצר מאושר: אין אזור ואין קיצור.
6. **עד שמסך הניהול ייבנה**: החלופות מוכנות בשיחה, אבי או שלי בוחרים בשרשור, ו-Claude רושם בטסט.
